# CT benchmark data catalog

This directory is the tracked, agent-readable knowledge entry for CT test
data.  Numeric arrays use versioned HDF5 files; each case has a searchable
`case.json` manifest with geometry, units, noise, provenance, tags, and SHA256.

Use the stable module interface:

```python
from inv_framework.benchmarks import list_ct_cases, load_ct_case, evaluate_ct_case
```

Case provenance has three meanings:

- `analytic_independent`: measurement comes from a closed-form reference and
  can test operator accuracy without using the implementation under test.
- `model_matched`: measurement is generated by the same operator family and
  is intended for solver/interface regression, not physical validation.
- `backend_reference`: measurement is generated by a named external backend
  and can support cross-version or cross-backend comparison.

Large or license-constrained real datasets are described in
`external_catalog.json` and are never downloaded by default CI.

The `quality` cases are 128 x 128 synthetic tissue phantoms authored with an
independent ASTRA line projector.  They are kept separate from the 32 x 32 CI
smoke cases and cover dense clean, sparse-view Poisson, and limited-angle
acquisition.  Their manifests explicitly say that they are synthetic rather
than patient data and record the display conversion to linear attenuation.
