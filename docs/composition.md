# Public composition boundary

Use `inv_framework.runner.run_experiment(config_or_path, output_dir=None, params=None)` or the domain task API. Python and CLI use the same runner; algorithm IDs and implemented choices come from each domain's `list_capabilities()`. See [algorithm index](algorithms/README.md) and [minimal calls](algorithm_examples.md).

Priority is algorithm configuration defaults < experiment `params` < explicit function `params`. CT aliases are normalized separately within each layer before merging: max_iter/num_iterations, num_subsets/subset_count, lam/strength, fidelity/data_fidelity; composable reg_strength/strength, Tikhonov strength/reg_strength and Landweber learning_rate/step_size are method dependent. Contradictory aliases in one layer fail. A top-level CT fidelity conflicting with params also fails. MRI/deconvolution fidelity is a request field; numerical/model-weight overrides remain in params. Results return effective_params; a declared budget is not a claim that all iterations ran. Fixed-point and native stopping details remain in diagnostics.

CT selectable data terms are implemented on FISTA, ADMM, PDHG (L2, Gaussian NLL, WLS, transmission Poisson NLL) and Landweber, CGLS, LSQR, CG, Tikhonov (quadratic terms only; augmented Landweber is unconstrained). Gaussian needs public sigma; WLS needs public weights and weight_source. Transmission NLL needs pure raw Poisson counts/I0, zero electronic noise/background and supported nonnegative constraints. It uses I0 exp(-scale Ax), unlike emission Poisson Ax. SIRT/SART/OS-SART and TV-FISTA retain fixed residual updates. MLEM/OSEM require emission data. FBP/FDK are analytic, constrained TV uses a residual ball rather than an optimization likelihood.

MRI shared ADMM/PDHG/FISTA/Landweber/CGLS/LSQR/CG and CG-SENSE/CS-TV/CS-wavelet accept fidelity=l2, gaussian_nll, wls. All use complex quadratics; W is inputs.data_weights (inverse variance), not its square root. Gaussian defaults to identity if weights are absent. WLS requires supplied weights. L2 refuses supplied weights to avoid silently ignoring them. Calibration, zero-filled, GRAPPA and VarNet have no optimization fidelity switch. No Poisson or real nonnegative complex MRI reconstruction is implemented.

Deconvolution TV-ADMM accepts l2/gaussian_nll (unit-variance equivalents) and poisson_nll. Absent explicit fidelity, model.noise_model selects its existing Gaussian/Poisson route. Richardson-Lucy/RL-TV have fixed emission Poisson likelihood; Wiener-Hunt, Hyper-Laplacian and blind methods have fixed Gaussian quadratic fits. Explicit incompatible fidelities fail; the dedicated TV-ADMM route does not implement arbitrary weights. Shared ADMM/PDHG/FISTA/Landweber/CGLS/LSQR/CG accept WLS via data_weights; transmission Poisson is not a deconvolution likelihood. Explicit TV-ADMM fidelity may intentionally differ from generation noise; diagnostics record both. Gain/background and boundary restrictions still apply to the chosen update.

Generation noise, observation preprocessing and reconstruction likelihood are distinct. CT case metadata and MRI/deconvolution model.noise_model record supplied generation information, not a conclusion inferred from the chosen solver. Unknown remains unknown. Acquisitions, coil maps, PSF origins/boundaries, gain and known noise calibration are model inputs rather than arbitrary tuning parameters. Existing domain format guides define their units and shapes.

ADMM, PDHG and FISTA share numerical updates across 2D parallel CT, native complex Cartesian SENSE and known-PSF scalar 2D deconvolution. Five single regularizers and joint ADMM TV+Haar are public. See [shared solver definitions and calls](composable_solvers.md) for weights, boundaries, Haar lowpass conventions, fixed block penalties, FFT conditions and precision exits. Landweber, CGLS, LSQR and independent CG also have public three-domain entries; see [quadratic baselines](quadratic_baselines.md). Existing domain-specific methods and optional backends retain their own restrictions. The [three runnable starting points](../examples/composition/README.md) establish representative composition workflows; a full parameter search or a joint-regularizer quality advantage is not required.
